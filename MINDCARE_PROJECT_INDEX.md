## 3. Правило начала работы

Перед серьёзной задачей по MindCare:

1. Открыть этот Index.
2. Проверить актуальный HEAD ветки `dev` и своей рабочей ветки.
3. Посмотреть свежие commits/merge других разработчиков.
4. Проверить релевантные `docs/HANDOFFS/`, `docs/BACKLOG.md` и `docs/DECISIONS.md`.
5. Только после этого планировать изменения.

Для AI-агентов **GitHub важнее памяти чата**, если речь идёт о фактическом состоянии кода.
