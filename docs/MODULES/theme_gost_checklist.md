# Чек-лист соответствия ГОСТ Р 52872-2019 (версия для слабовидящих)

Реализация: `mindcare_web/src/features/a11y/` + `src/styles/tokens/a11y.css`.
Связанные документы: [`theme_implementation_plan.md`](theme_implementation_plan.md),
[`theme_deferred_plan.md`](theme_deferred_plan.md).

## Что реализовано (автоматически проверяется)

| Требование | Реализация | Проверка |
|---|---|---|
| Кнопка «Версия для слабовидящих» на каждой странице, доступна по Tab, есть `aria-label` | `A11yToggle` в `Navbar` и в topbar `CabinetLayout` | `A11y.test.jsx` |
| Выход — «Обычная версия» | тот же контрол, `aria-pressed` | `A11y.test.jsx` |
| Панель настроек закреплена под шапкой | `A11yPanel` в `Navbar` и `CabinetLayout` | `A11y.test.jsx` |
| Размер шрифта A / A+ / A++ (100 / 150 / 200 %) | `--a11y-font-scale` + `zoom` на `:root` | `A11y.test.jsx` |
| Схемы: Ч/Б, Б/Ч, синяя (#9DD1FF/#063462), бежевая (#F7F3D6/#4D4B31) | `data-a11y-scheme` | `npm run test:contrast` (все 4 ≥ 7:1) |
| Межбуквенный интервал: обычный / 0.05em / 0.1em | `data-a11y-spacing` | `A11y.test.jsx` |
| Межстрочный интервал: 1.5 / 2 | `data-a11y-leading` | `A11y.test.jsx` |
| Шрифт: без засечек / с засечками | `data-a11y-font` | `A11y.test.jsx` |
| Изображения: показать / скрыть (остаётся alt в рамке) / оттенки серого | `data-a11y-images`; при «скрыть» снимается `src` → браузер рендерит alt (+ MutationObserver для SPA) | `A11y.test.jsx` |
| Кнопка «Сбросить настройки» | `A11yPanel` → `reset()` | `A11y.test.jsx` |
| Настройки сохраняются между визитами | localStorage `app-a11y-settings` | `A11y.test.jsx` |
| Одноколоночная упрощённая сетка, текст ≤ 80ch | `a11y.css`: `main/.container { max-width: 80ch }`, grid → `display: block` | ручная (см. ниже) |
| Отключены декоративные элементы, фоновые изображения, анимации | `a11y.css`: `background-image/animation/transition: none` | ручная |
| Брендовые цвета не используются; ссылки подчёркнуты | все токены сведены к паре `--a11y-bg/--a11y-fg`; `a { text-decoration: underline }` | `a11y.css` |
| Все контролы панели доступны с клавиатуры | `button` + `aria-pressed` + видимый фокус 3px | `A11y.test.jsx` |

Помимо ГОСТ-режима есть отдельные высококонтрастные темы `hc-light` / `hc-dark`
(AAA ≥ 7:1, авто-включение по `prefers-contrast: more`).

## Ручная приёмка (обязательна перед сдачей — НЕ автоматизируется)

- [ ] Запись на консультацию (`/student/calendar`) полностью выполнима **с клавиатуры**
      в режиме a11y при шрифте 200%.
- [ ] Прохождение теста (`/student/tests`) полностью выполнимо с клавиатуры при 200%.
- [ ] При ширине окна **320px CSS** и шрифте 200% нет горизонтального скролла
      на: главная, услуги, материалы, запись, тест, оба кабинета.
- [ ] При «скрыть изображения» смысл страниц сохраняется через alt-тексты
      (проверить новости, материалы, аватары, вложения чата).
- [ ] Кнопка «Версия для слабовидящих» видна и работает на всех страницах,
      включая кабинеты студента, психолога, супервизора, админа.
- [ ] Статусы записей и результаты тестов не кодируются **только цветом**
      (в схеме Ч/Б цвет отсутствует — смысл должен читаться из текста/иконки).
- [ ] Прогресс теста имеет текстовый эквивалент («Вопрос N из M»).
- [ ] Проверка в NVDA/VoiceOver: панель настроек и навигация озвучиваются.

## Известные ограничения текущей реализации

- Масштаб шрифта реализован через `zoom` на `:root` — это увеличивает и layout
  (иначе 200% недостижимы: часть компонентов использует px). Требует ручной
  проверки на 320px (пункт выше).
- Правило скрытия декоративных блоков опирается на имена классов
  (`[class*='decor']`, `[class*='illustration']`) — при появлении новых
  декоративных компонентов проверять вручную.
- Дублирование смысла текстом там, где сейчас только цвет (статусы appointments,
  интерпретации тестов), точечно не проверялось — входит в ручную приёмку.
