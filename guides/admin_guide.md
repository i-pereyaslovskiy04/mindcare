# Руководство пользователя: панель администратора

Платформа психологической службы ДонГУ MindCare. Администратор управляет сотрудниками (психологами, супервизорами, другими администраторами), контентом сайта (новости, статьи, темы, типы материалов), психодиагностическими тестами, типами встреч, списком разрешённых доменов почты для регистрации и своей учётной записью.

Первый администратор системы создаётся отдельным серверным скриптом при развёртывании платформы (`scripts/create_admin.py`) — все последующие сотрудники создаются уже через панель администратора.

## 1. Вход в систему

1. На форме входа введите **Email** и **Пароль** своей учётной записи администратора.
2. Нажмите **«Войти»**.
3. Система автоматически откроет панель администратора (`/admin/users`).

Если забыли пароль — используйте ссылку **«Забыли пароль?»** на форме входа (код подтверждения приходит на почту).

---

## 2. Общая навигация панели

Левое меню панели администратора сгруппировано в четыре блока:

- **Управление**: Пользователи
- **Контент**: Материалы, Новости, Тесты
- **Система**: Типы материалов, Темы, Типы встреч, Домены регистрации
- **Аккаунт**: Безопасность

При заходе в раздел `/admin` без указания страницы система автоматически откроет «Пользователей».

> В интерфейсе используются пользовательские названия разделов: **«Темы»** (в базе данных — `tags`) и **«Типы материалов»** (в базе данных — `categories`). Если вы видите эти технические названия в других документах или в адресной строке — это те же самые разделы.

## 3. Пользователи

Раздел **«Пользователи»** (`/admin/users`) — управление учётными записями сотрудников и просмотр всех пользователей платформы.

### Таблица пользователей

Колонки: ФИО, Email, Роль (одна или несколько плашек — пользователь может одновременно иметь несколько ролей), Статус («Активен» / «Заблокирован» / «Удалён»), Дата регистрации, Последний вход.

Доступны фильтры: поиск по имени/email, фильтр по роли, фильтр по статусу и чекбокс **«Показать удалённых»**.

### Как создать нового сотрудника

1. Нажмите **«+ Добавить»**.
2. Заполните **ФИО** и **Email**.
3. Отметьте одну или несколько служебных ролей: **Администратор**, **Супервизор**, **Психолог**. Роль «Студент» через эту форму назначить нельзя — студенты появляются только через регистрацию на сайте или через раздел «Запись» в кабинете супервизора.
4. Заполните блок документированного основания для создания учётной записи и обработки персональных данных сотрудника:
   - **«Тип основания»** — служебная необходимость, трудовое основание, договор, административный приказ или иное;
   - **«Документ-основание»** — например, «Приказ № 15‑к от 01.07.2026» (обязательное поле);
   - при желании — комментарий;
   - отметьте чекбокс подтверждения наличия документированного основания.
5. Нажмите **«Создать»**.
6. На экране появится временный пароль нового сотрудника — он также автоматически отправляется на указанную почту. Передайте пароль сотруднику или попросите его проверить почту.

> Это НЕ согласие сотрудника на обработку своих персональных данных, а организационное (кадровое) основание для создания учётной записи — формулировки в системе намеренно разделяют эти два понятия.

### Как изменить роли пользователя

1. Найдите пользователя, нажмите значок редактирования.
2. Если у пользователя уже есть хотя бы одна служебная роль — чекбоксы ролей активны, можно добавить или снять роль.
3. Если у пользователя нет ни одной служебной роли (например, только роль «Студент» или вообще без ролей) — блок ролей заблокирован. Первую служебную роль пользователю можно выдать только через **«+ Добавить»** (создание нового пользователя), а не через редактирование.
4. При добавлении новой служебной роли форма потребует заполнить документированное основание (аналогично созданию нового сотрудника) и подтвердить чекбоксом.
5. Роль **«Студент»**, если она у пользователя есть, показывается отдельной неизменяемой плашкой — снять или изменить её через эту форму нельзя.
6. Нажмите **«Сохранить»**.

**Важные ограничения:**
- Администратор не может снять роль «Администратор» у самого себя — чекбокс заблокирован с подсказкой «Нельзя снять у себя роль администратора». Изменить чужой набор ролей администратора может другой администратор.
- У пользователя всегда должна оставаться хотя бы одна роль — снять все служебные роли можно только если у него сохраняется роль «Студент», иначе система покажет ошибку.

### Как деактивировать пользователя

1. Нажмите значок корзины в строке пользователя.
2. Подтвердите в диалоге «Удалить пользователя» — учётная запись будет деактивирована, все её активные сессии входа завершатся.

Это не физическое удаление (soft delete) — деактивированные пользователи остаются видны в списке при включённом фильтре «Показать удалённых».

## 4. Темы

Раздел **«Темы»** (`/admin/tags`) — справочник тематических меток, которые можно присваивать статьям, новостям и тестам (например, «Тревога», «Стресс», «Сон»).

### Как создать тему

1. Нажмите **«+ Новая тема»**.
2. Введите название (система автоматически сделает первую букву заглавной, остальные — строчными).
3. Нажмите **«Создать»**.

### Как удалить тему

Нажмите значок удаления у нужной темы и подтвердите. Если тема уже используется в статьях, новостях или тестах, система предупредит о количестве связанных материалов — при подтверждении все связи с этой темой будут автоматически удалены (сами материалы не удаляются).

В таблице тем видно, сколько раз тема использована в статьях, новостях и тестах.

## 5. Новости

Раздел **«Новости»** (`/admin/news`) — публикация новостей на сайте.

### Как создать и опубликовать новость

1. Нажмите **«+ Добавить»**.
2. Заполните **«Заголовок»** (обязательно) и текст в редакторе.
3. При желании загрузите обложку (перетащите файл или выберите вручную).
4. Выберите одну или несколько тем.
5. Укажите дату публикации.
6. Нажмите **«Предпросмотр»**, чтобы посмотреть, как новость будет выглядеть на сайте.
7. Отметьте чекбокс **«Опубликовать»**, если новость должна быть видна сразу, и нажмите **«Создать и опубликовать»**. Если оставить чекбокс не отмеченным — нажмите **«Сохранить черновик»**, новость сохранится, но не будет видна на сайте до публикации.

Фильтры в списке: поиск по заголовку, статус («Опубликованные» / «Черновики»).

### Как удалить новость

Значок удаления в строке новости, подтверждение в диалоге — удаление необратимо.

## 6. Материалы

Раздел **«Материалы»** (`/admin/articles`) — статьи, упражнения и другой обучающий контент библиотеки.

### Как создать материал

1. Нажмите **«+ Добавить»**.
2. Заполните **«Заголовок»**, краткое описание (для карточки материала на сайте) и полный текст в редакторе.
3. При желании загрузите обложку.
4. Выберите **«Тип (категория)»** — один или несколько типов материала (см. [раздел 7](#7-типы-материалов)).
5. Выберите **«Темы»**.
6. Укажите дату публикации.
7. Проверьте оформление кнопкой **«Предпросмотр»**.
8. Отметьте **«Опубликовать»** и нажмите **«Создать и опубликовать»** — либо сохраните как черновик.

Удаление материала аналогично удалению новости — необратимо, требует подтверждения.

## 7. Типы материалов

Раздел **«Типы материалов»** (`/admin/categories`) — справочник категорий контента (например, «Статья», «Упражнение», «Аудиопрактика»), которые предлагаются при добавлении материала.

### Как создать тип материала

1. Нажмите **«+ Добавить тип»**.
2. Укажите **«Название»** (обязательно).
3. При желании укажите технический адрес («Slug») — если оставить пустым, он сформируется автоматически из названия.
4. При желании заполните описание и порядок отображения (число — чем меньше, тем выше в списке).
5. Отметьте **«Активна (показывать в формах добавления материалов)»**.
6. Нажмите **«Сохранить»**.

### Как скрыть тип материала

«Удаление» типа материала на самом деле деактивирует его — тип перестаёт предлагаться при добавлении новых материалов, но уже существующие материалы с этим типом не теряют привязку. Подтвердите действие в диалоге «Скрыть тип материалов?».

## 8. Тесты (конструктор психодиагностики)

Раздел **«Тесты»** (`/admin/tests`) — создание и редактирование психодиагностических методик, которые студенты проходят в своём кабинете.

### Список тестов

Таблица: название и категории теста, количество вопросов, способ подсчёта («Сумма баллов» / «Среднее значение»), статус («Активен» — виден студентам в каталоге, или «Скрыт»).

### Как создать тест

1. Нажмите **«+ Создать тест»**.
2. В блоке **«Основное»** заполните название, описание, выберите метод подсчёта, при желании укажите лимит времени (в минутах), типы материалов и темы. Отметьте **«Активен»**, если тест должен сразу появиться в каталоге студентов.
3. В блоке **«Вопросы»** нажмите **«+ Добавить вопрос»** для каждого вопроса методики:
   - введите текст вопроса;
   - выберите тип ответа: один вариант, несколько вариантов, шкала (ползунок) или свободный текст;
   - для многошкальных методик укажите название шкалы (например, «Тревога», «Депрессия») — если оставить поле пустым, вопрос учитывается в общем итоговом балле;
   - отметьте, обязателен ли вопрос для ответа;
   - для вариантов ответа — добавьте не менее двух вариантов и укажите балл каждого варианта;
   - для шкалы — задайте минимум, максимум и шаг.
   - порядок вопросов можно менять стрелками «Выше»/«Ниже».
4. В блоке **«Интерпретация результатов»** добавьте пороги: диапазон баллов «От»–«До», название уровня (например, «Высокий уровень») и текст рекомендации, который увидит студент. Оставьте поле «Шкала» пустым для интерпретации по итоговому баллу, либо укажите название конкретной шкалы для многошкальных тестов.
5. Проверьте панель анализа под интерпретациями — она автоматически показывает достижимый диапазон баллов по каждой шкале и предупреждает, если часть диапазона не покрыта ни одним порогом или порог указывает на недостижимый балл. Эти предупреждения **не блокируют сохранение теста** — их можно оставить осознанно или исправить диапазоны.
6. Нажмите **«Предпросмотр»**, чтобы пройти тест как студент (баллы вариантов в предпросмотре не показываются) и нажать **«Посчитать результат»** — это пробный подсчёт, ничего не сохраняющий.
7. Нажмите **«Создать тест»**.

**Правило про шкалы:** если хотя бы у одного вопроса указана шкала, то шкала должна быть указана у всех вопросов, участвующих в подсчёте (правило «все или ни одной») — иначе форма предупредит и не даст сохранить с частичным заполнением.

### Как отредактировать существующий тест

Откройте тест из списка. Если по этому тесту студенты **уже проходили** его и есть сохранённые результаты — изменить вопросы и варианты ответов нельзя (иначе прежние ответы студентов потеряли бы смысл). Система покажет предупреждение и предложит кнопку **«Создать копию и править её»** — копия теста создаётся как неактивный черновик, скрытый из каталога, пока вы не активируете его вручную. Метаданные теста (название, описание, категории, темы, интерпретации) редактировать можно всегда, даже если результаты уже есть.

Кнопка **«Дублировать»** доступна на любом сохранённом тесте, даже без результатов — например, чтобы создать похожую методику на основе существующей.

### Как удалить тест

«Удаление» теста скрывает его из каталога студентов — уже полученные студентами результаты сохраняются и остаются доступны студентам в их истории.

## 9. Типы встреч

Раздел **«Типы встреч»** (`/admin/meeting-types`) — тот же справочник, что доступен супервизору (форматы консультаций и групповых занятий с указанием длительности и буфера между записями). Администратору доступны те же действия, что и супервизору:

1. Нажмите **«+ Добавить»**, укажите название, описание, длительность (10–480 мин), буфер после встречи (0–120 мин), доступные форматы («Онлайн»/«Очно»), отметьте «Доступен для записи» и «Активен».
2. Для группового типа встречи (чекбокс «Групповой формат») обязательно выбрать ровно один формат — либо «Онлайн», либо «Очно».
3. Кнопка **«Отключить»**/**«Включить»** в строке таблицы мгновенно переключает доступность типа встречи.

## 10. Домены регистрации

Раздел **«Домены регистрации»** (`/admin/email-domains`) — управляет списком доменов электронной почты, с которых разрешено создавать новые аккаунты (самостоятельная регистрация студентов, создание сотрудников, создание студентов супервизором).

> Уже существующие пользователи с доменом, которого нет в списке или который отключён, продолжают пользоваться платформой без ограничений — правило действует только на создание НОВЫХ аккаунтов.

### Как добавить домен

1. Введите домен в поле **«Домен»** (например, `donnu.ru`, без `@`).
2. При желании добавьте комментарий (например, «основной вуз»).
3. Нажмите **«Добавить»**.

### Как отключить домен

1. Нажмите **«Отключить»** у нужного домена.
2. Подтвердите в открывшемся окне — система предупредит, что новые аккаунты с этим доменом создавать будет нельзя, а существующие пользователи не пострадают.

**Ограничение:** отключить последний оставшийся активный домен нельзя — система вернёт ошибку «Нельзя отключить последний активный домен: хотя бы один домен должен оставаться активным». Сначала добавьте или включите другой домен.

### Как снова включить домен

Нажмите **«Включить»** у отключённого домена — действие выполняется сразу, без дополнительного подтверждения.

> Физического удаления доменов из списка нет — только отключение и повторное включение. Это сделано намеренно, чтобы сохранять историю изменений allowlist.

## 11. Безопасность (настройки аккаунта)

Раздел **«Безопасность»** (`/admin/settings`) содержит только смену пароля вашей учётной записи.

1. Введите «Текущий пароль».
2. Введите «Новый пароль» (не короче 8 символов) и повторите его в поле подтверждения.
3. Нажмите **«Сменить пароль»**.
4. После успешной смены появится сообщение «Пароль изменён. Войдите снова.» — система автоматически завершит сеанс, войдите заново с новым паролем.

## 12. Сводка ограничений и защитных механизмов

| Ограничение | Где применяется |
|---|---|
| Нельзя снять у себя роль «Администратор» | Пользователи → редактирование своей записи |
| Первую служебную роль можно выдать только при создании нового пользователя | Пользователи → редактирование |
| Роль «Студент» не назначается через админку | Пользователи (создание и редактирование) |
| Добавление служебной роли требует документированного основания | Пользователи (создание и добавление роли) |
| У пользователя должна остаться хотя бы одна роль | Пользователи → редактирование |
| Вопросы теста с уже полученными результатами менять нельзя | Тесты → редактирование (предлагается дублировать тест) |
| Групповой тип встречи должен иметь ровно один формат | Типы встреч, Типы встреч (админ) |
| Нельзя отключить последний активный домен регистрации | Домены регистрации |
| У доменов регистрации нет физического удаления, только отключение/включение | Домены регистрации |
| «Удаление» типа материала — деактивация, привязки сохраняются | Типы материалов |
| «Удаление» теста — скрытие из каталога, результаты студентов сохраняются | Тесты |
| «Удаление» пользователя — деактивация (soft delete), все сессии завершаются | Пользователи |
| Пороги интерпретации теста, не покрывающие весь диапазон баллов, — только предупреждение, не блокируют сохранение | Тесты → конструктор |
