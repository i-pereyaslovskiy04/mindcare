# Руководство пользователя: личный кабинет психолога

Платформа психологической службы ДонГУ MindCare. Аккаунт психолога создаёт администратор — самостоятельная регистрация психологов на сайте не предусмотрена. В этом руководстве описаны все разделы кабинета психолога: список студентов, консультации, расписание, чат и настройки.

## 1. Вход в систему

1. Свою учётную запись и временный пароль вы получаете от администратора (пароль присылается на почту при создании аккаунта).
2. На форме входа введите **Email** и **Пароль**, нажмите **«Войти»**.
3. При первой возможности рекомендуется сменить временный пароль в разделе «Настройки» (см. [раздел 9](#9-настройки-аккаунта)).
4. Если забыли пароль — на форме входа есть ссылка **«Забыли пароль?»**, восстановление проходит через код, отправленный на вашу почту.

После входа система автоматически откроет кабинет психолога (`/psychologist`).

## 2. Главная страница кабинета

Страница `/psychologist` — приветственный экран. Здесь показаны:

- Приветствие с вашим именем и сегодняшней датой.
- Карточка **«Ближайшие встречи»** — реальный список консультаций и групповых занятий на сегодня и на ближайшие 7 дней (учитываются записи в статусах «ожидает подтверждения»/«подтверждена» и запланированные группы).
- Блок статистики («Сессий за месяц», «Клиентов», «Непрочитанных») — на данный момент это заглушки с прочерком, раздел развивается.

Реальная работа с клиентами и записями ведётся в разделах «Мои студенты» и «Сессии» — с главной страницы туда нужно переходить через меню слева.

## 3. Мои студенты

Раздел **«Мои студенты»** (`/psychologist/students`) показывает студентов, которых вам назначил супервизор (это называется активным сопровождением, или *engagement*).

- Доступен поиск по ФИО или email.
- Каждая карточка студента: ФИО, email, дата назначения, бейдж «Активен».
- Кнопка **«Открыть карточку»** ведёт на карточку студента.
- Кнопка **«Чат со студентом»** — быстрый переход в переписку (если диалог уже существует).

**Важно:** список студентов формируется супервизором. Психолог не может добавить или убрать студента самостоятельно — только видит тех, кого ему назначили.

Если студентов пока нет, показывается сообщение «Пока нет назначенных студентов» — обратитесь к супервизору, чтобы он назначил вам студента.

---

## 4. Карточка студента

Страница `/psychologist/students/:studentId` открывается по клику «Открыть карточку» из списка студентов. Здесь видны:

- ФИО, email студента, дата назначения и длительность сопровождения.
- Статус сопровождения — бейдж «Активен».
- Блок **«Быстрые действия»** — на сегодняшний день реально работает только кнопка **«Чат со студентом»**.

> Кнопки «Расписание», «Заметки», «Материалы и тесты» на карточке студента пока недоступны (помечены как «скоро») — рабочие заметки психолога, назначение материалов и просмотр результатов психодиагностики студента находятся в разработке и появятся в следующих версиях платформы.

## 5. Сессии — индивидуальные записи

Раздел **«Сессии»** (`/psychologist/appointments`) содержит три вкладки: **«Индивидуальные»**, **«Групповые»**, **«Моё расписание»**.

### Вкладка «Индивидуальные»

- Фильтр по статусу: **Все / Ожидают / Подтверждённые / Завершённые / Отменённые**.
- Мини-календарь месяца с точками-индикаторами по дням; клик по дню раскрывает список встреч этого дня.
- Список карточек записей: имя клиента (или пометка «Карточка», если это запись walk‑in клиента без аккаунта, созданная супервизором), статус, дата и время (по Москве), тип и формат встречи (онлайн/очно), тема встречи (если указана), причина отмены/отклонения (если применимо).

### Как подтвердить или отклонить запись

1. Найдите запись со статусом **«Ожидает подтверждения»**.
2. Нажмите **«Подтвердить»** — запись переходит в статус «Подтверждена», студент увидит это в своём календаре.
3. Либо нажмите **«Отклонить»** — откроется окно, где можно (необязательно) указать причину отклонения, затем нажмите **«Отклонить»**.

### Статусы записи

| Статус | Что означает |
|---|---|
| Ожидает подтверждения | Требуется ваше решение |
| Подтверждена | Вы приняли запись |
| Отменена студентом | Студент сам отменил запись |
| Отклонена | Вы отклонили запись |
| Завершена | Консультация состоялась |
| Не явился | Студент не пришёл на встречу |

Действия «Подтвердить»/«Отклонить» доступны только для записей в статусе «Ожидает подтверждения» — остальные статусы показываются только для просмотра.

## 6. Сессии — групповые занятия

Вкладка **«Групповые»** показывает список групповых занятий, которые супервизор назначил вести вам: название, статус («Запланировано» / «Завершено» / «Отменено»), признак записи («Запись открыта»/«Запись закрыта»), дата/время, количество занятых/всего мест, формат.

Эта вкладка предназначена только для просмотра — управление групповыми занятиями (создание, изменение времени, открытие/закрытие записи) выполняет супервизор.

---

## 7. Сессии — моё расписание

Вкладка **«Моё расписание»** показывает ваше рабочее расписание, сгруппированное по дням недели: рабочие окна («Рабочее время: HH:MM–HH:MM»), период действия, признак автопродления, повторяющиеся перерывы (например, обед), а также разовые изменения — выходные дни, блокировки и дополнительные окна доступности на конкретные даты.

> **Расписание строго доступно только для просмотра.** Настраивает и меняет ваше рабочее время супервизор — в кабинете психолога нет инструментов для редактирования расписания. Если нужно внести изменения (отпуск, смена рабочих часов) — обратитесь к своему супервизору.

## 8. Сообщения (чат со студентами)

Раздел **«Сообщения»** (`/psychologist/chat`) — переписка с назначенными вам студентами.

1. Слева выберите диалог. Отдельно закреплён пункт **«Системные уведомления»** — односторонние уведомления платформы (ответить в них нельзя).
2. Введите сообщение в поле **«Напишите сообщение…»**, нажмите **«Отправить»** (или Enter на компьютере).
3. Прикрепить файл можно кнопкой‑скрепкой или перетаскиванием файла в окно чата.
4. Своё сообщение можно отредактировать или удалить через меню «…» рядом с ним.

**Ограничения:**
- Доступны только диалоги со студентами, официально назначенными вам (активное сопровождение).
- Если сопровождение студента завершено, диалог переходит в режим только для чтения — переписка сохраняется, но отправить новое сообщение нельзя.
- В «Системных уведомлениях» ответить нельзя.
- Максимальная длина сообщения — 10 000 символов.

Быстрый переход в чат с конкретным студентом доступен также из списка «Мои студенты» и с карточки студента (кнопка «Чат со студентом»).

## 9. Настройки аккаунта

Раздел **«Настройки»** (`/psychologist/settings`).

### Что сохраняется по-настоящему

**Смена пароля** (блок «Безопасность»): заполните «Текущий пароль», «Новый пароль», «Подтверждение нового пароля», нажмите **«Изменить пароль»**. После успешной смены система автоматически завершит сеанс — войдите заново с новым паролем.

### Визуальные заготовки (пока не сохраняются на сервере)

Поля профиля («Имя», «Номер телефона», «Часовой пояс»), кнопка «Изменить фото» и переключатели уведомлений («Напоминания о сессиях», «Новые сообщения», «Еженедельный итог») на этой странице сейчас не отправляются на сервер и сбрасываются при обновлении страницы.

### Тема оформления и режим для слабовидящих

Настраиваются из значков в верхней панели кабинета (не на странице настроек) и сохраняются в профиле по-настоящему: режим «Светлая» / «Тёмная» / «Системная», палитра «Кофе» / «Природа» / «Классика» / «Контраст», а также отдельный режим для слабовидящих по ГОСТ Р 52872‑2019.

## 10. Что пока не работает по-настоящему

- Кнопка **«Настройки профиля»** на главной странице кабинета.
- Статистика на главной странице («Сессий за месяц», «Клиентов», «Непрочитанных»).
- Пункт меню **«Материалы»** — недоступен.
- На карточке студента: **«Расписание»**, **«Заметки»**, **«Материалы и тесты»** — в разработке.
- Редактирование собственного расписания — доступно только супервизору.
- На странице настроек: поля профиля, фото, часовой пояс, переключатели уведомлений.

Реально работающий функционал: список назначенных студентов, подтверждение/отклонение индивидуальных записей, просмотр группы и расписания, переписка со студентами, смена пароля, тема оформления и режим для слабовидящих.
